Ralph Loop by Igor Ganapolsky

The autonomous agentic loop that powers ResumeOS audits.

What it is

Ralph Loop is my production implementation of the Ralph pattern — an LLM agent running in a loop, re-anchoring from files on every iteration instead of accumulating a transcript. Each pass picks its own task from a structured spec, ships a small change with evidence, and exits cleanly.

This is the system behind ResumeOS résumé audits, the autonomous UpWork money loop, and the Hilltown Media Group Pretix-Stripe-Connect contract delivery.

What's different from other Ralph implementations

  • Audit-grade evidence trail. Every action commits a signed artifact (screenshot, JSON proof, hash). Nothing is claimed without a file you can cat.
  • Cap-aware Thompson-sampling lane scheduler. Knows that Alignerr is 5/24h, UpWork Boost has 7-day windows, Greenhouse v3 has per-tenant score gates. Doesn't burn cycles on dead lanes.
  • Real-browser drivers. Patchright + CDP-attach to your already-logged-in Chrome. No bundled-Chromium reCAPTCHA fails. No "Computer Use" focus-routing bugs on Workday React inputs.
  • ThumbGate-integrated. Hard gates on push-without-tests, secret exfiltration, scope creep. The loop refuses to ship work that hasn't proven itself.
